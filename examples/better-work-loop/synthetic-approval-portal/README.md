# Synthetic Better Work Loop walkthrough

This fictional example continues the `process-before-platform` approval-request scenario through shaping, building, proof, and a review-ready handoff.

It demonstrates:

- one stable initiative and loop identity;
- three explicitly different process views: evidenced current state, stakeholder-stated ideal, and agent-proposed target design;
- one bounded handoff mapped to stable target-process nodes, with requester/user/downstream/owner roles separated;
- one accepted build gate;
- a dependency-free, local vertical slice;
- technical and synthetic scenario coverage;
- an honest `agent-verified` result because no representative user was observed;
- a ready-to-run user session and a next decision to seek evidence rather than claim validation or pilot readiness;
- a handoff that business, PM/PO, and delivery reviewers can understand without reconstructing the prototype conversation.

Open `prototype/index.html` locally to exercise the slice. None of these artifacts contains real organizational data or counts as a behavioral evaluation of the pack.
